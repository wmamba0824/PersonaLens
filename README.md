# PersonaLens｜人物画像提取与风格问答

从创作者的历史内容提炼有依据的 AI 人物画像，再结合本地知识库进行有出处的风格问答。

这是我的第一版 Vibe Coding 作品，也是可独立运行的模板。**AI 模拟，不是本人；公开内容不等于获得使用或传播授权。**

最近一批改动：网页API/B站配置、统一人物资料、本地人物、最近对话恢复及Markdown导出，见[更新记录](CHANGELOG.md)。

## 当前能做什么

- 输入 B站主页或数字 UID，有限采集本人公开文字和可用视频字幕。
- 无字幕时，可显式选择下载有限音轨并用本地 Whisper 转录；不会自动安装或下载模型。
- 从有限样本提炼可编辑画像，查看依据、人工确认后启用。
- 本地生成中文向量并缓存，无需云端向量 API Key；失败时明确提示关键词兜底。
- 结合画像与检索资料进行问答，展示原文、日期和来源；不同人物资料、画像和索引隔离。
- 可直接用自己的 TXT、Markdown（`.md` / `.markdown`）问答，也可导入已导出的同人物公众号原文 JSON。
- 首次在网页填写API配置，无需手动编辑`.env`；已有配置继续兼容。
- B站登录Cookie也可在侧栏“B站采集设置”填写并保存在本机；已存值不回显，保存不自动联网，旧`.env`继续兼容。
- 同一个人物可混合B站采集和网页上传的TXT/MD，也可不提供B站ID、直接建立本地人物。
- 从“我的人物”重新打开已保存的人物，继续最近10轮对话，导出画像和问答Markdown。
- Windows 自动安装项目依赖、后台启动网页，支持可选可信局域网访问。

```text
主页 / UID → 公开文字或视频字幕 ─┐
同人物 TXT / Markdown 网页导入 ─┼→ 同一人物知识库 → 提炼画像、审核 → 风格问答
已有同人物公众号原文 JSON ──────┘
```

不保证任意博主一键成功：资料需有足够本人表达，背景歌、标题、转载不能当本人观点；至少3条内容、600字有效文字才开放人物画像。

## 快速开始（Windows）

先安装 Python（新环境推荐3.11/3.12，勾选 Add Python to PATH），将项目放在短路径，例如 `D:\AI\PersonaLens`。

```powershell
git clone https://github.com/wmamba0824/PersonaLens.git
cd PersonaLens
.\setup_local.bat
```

安装器创建独立`.venv`，安装最小依赖；不覆盖已有`.env`或修改系统Python。
双击`start_local.bat`，打开`http://127.0.0.1:8501/`。停止使用`stop_local.bat`。

首次网页会显示配置引导：填写自己的聊天API Key，默认接DeepSeek；接口和模型可在高级选项修改。
点击“保存配置并开始”只保存到本机，不联网或消耗API额度，不需要手改配置文件。
旧`.env`仍可用；网页保存的设置优先，修改后下次请求立即生效。已保存Key不会回显。

网页默认进入“人物助手”：

1. 输入B站UID/主页打开人物；或者展开“没有B站ID？”填写名称，建立本地人物。仅建立不采集、不调用API。
2. 确认权限，采集B站资料，或在同一个人物下上传TXT/MD原文；两类来源共同用于画像和问答。
3. 同意有限样本外发，生成人物画像草稿。
4. 对照样本编辑和审核，确认画像后准备本地索引。
5. 同意聊天外发后提问，展开“本次实际参考资料”核对来源。

刷新不会重新采集或提炼。已有人物从侧栏“我的人物”打开；最近对话在本机复用。
资料变化后旧画像和旧版本对话不再应用，需重新生成并审核。部分采集仍需本地平台登录态，见[使用指南](docs/USAGE.md)。

“API设置”管理聊天模型；“B站采集设置”管理自己的`SESSDATA`、`bili_jct`、`buvid3`、`DedeUserID`。
两者互不替代。没有做扫码登录或自动读取浏览器Cookie；填写后会复用，失效时自己更新。
HTTP412表示这次请求被拒绝，不能单凭它确定原因；填Cookie也不保证能采集，不自动重试或绕过。

### 已有 TXT、Markdown、公众号或视频

- **人物资料**：在人物页面直接上传`.txt`、`.md`、`.markdown`并确认作者归属；每次最多20份/8MB，单份2MB/20万字。同名更新、正文重复跳过，不自动猜作者或发布日期。画像仍要求至少3份独立资料、600字，不能重复上传凑数。
- **只想问资料，不做人物**：仍可把文件放入`knowledge/`，切换“本地资料问答”。Markdown按文本读取，不执行代码或抓取链接；README等说明文件不参与检索。可选虚构示例见[examples](examples/README.md)，详细规则见[资料目录说明](knowledge/README.md)。
- **公众号JSON**：离线导入已有原文导出，不是任意链接爬虫；见[导入格式](docs/USAGE.md#公众号原文-json)。
- **无字幕视频**：先显式运行下面命令准备可选本地转录，再在网页勾选本机转录。

```powershell
.\setup_video.ps1 -DownloadModel
```

语音模型约486MB，不随仓库提供。默认只识别每条开头180秒，不是全量直播转录。

## API、隐私和费用

默认聊天接DeepSeek。其他兼容接口可在本机网页“API设置”修改完整HTTPS聊天地址和模型名，
也兼容`.env`中的`DEEPSEEK_API_URL`与`DEEPSEEK_CHAT_MODEL`，但不承诺任意厂商只换Key即可使用。

向量和可选语音识别在本机处理；画像提炼、聊天使用你配置的云端API并消耗额度。
画像最多发送12,000字样本；人物聊天发送问题、画像、必要历史及最多6,000字检索上下文块，不是整库上传，也不是完全离线AI。

`.env`、用户TXT/Markdown、`.runtime`、模型、索引和日志均不应提交；只能导入你有权使用、且允许发送给所配置API的资料。
网页API配置以本机明文文件保存于被Git忽略的`.runtime/api-settings.json`，不是加密密钥库；不要打包该目录分享。
B站登录配置同样是本机明文文件`.runtime/bilibili-settings.json`，不随人物导出；只用于固定B站API域名，字幕/音频使用无登录凭证的独立会话。
详细边界见[隐私与使用范围](docs/PRIVACY.md)。

## 本机与手机

- 本机：`start_local.bat`，仅监听`127.0.0.1`。
- 手机同一可信Wi-Fi：停止后运行`start_lan.bat`，打开脚本输出地址并输入访问码。访客会使用这台电脑的资料和API额度。
- API和B站登录配置仅在本机模式可修改；请先完成本机配置，再切换局域网模式，手机不显示Key/Cookie或配置表单。
- 端口被占用：先检查对应服务，或运行`powershell -ExecutionPolicy Bypass -File .\start_local.ps1 -Port 8502`。

不要公网端口转发。本模板不包含在线托管、公共账号/支付、多租户或已部署站点。

```text
chat_app.py        独立网页入口
app/ingest/       采集、画像、审核、人物存储与问答
app/rag/          本地向量与关键词兜底

scripts/          自检、公众号导入与本地转录准备
```

本模板从维护项目的白名单源码整理，初始化全新Git仓库；不附带旧人物原文、画像、向量、Key或维护者账号状态。
历史功能验证与独立模板测试分开记录，见[验证说明](docs/VALIDATION.md)。

```powershell

.\.venv\Scripts\python.exe -m pytest -q

.\.venv\Scripts\python.exe scripts/check_release.py
```

常规测试禁止未模拟的HTTP请求，不自动消耗聊天额度或下载模型。真实回答可能有误，引用编号合法也不等于所有解释获得原文支持。
