# 放入你的 TXT 或 Markdown

把一个或多个 `.txt`、`.md`、`.markdown` 文件放在这个目录（支持子目录、混用及大小写后缀），
网页选择“本地资料问答”，启动或点击“重新加载资料”。

自动读取时跳过隐藏文件/目录、符号链接和解析到目录外的文件。
Markdown说明文件 `README.md`、`README.*.md`、`AGENTS.md`、`SKILL.md` 不作为知识导入，
上述名称不区分大小写，换成 `.markdown` 后缀也一样。如果它们是正式资料，请换个文件名。

支持 UTF-8（含 BOM）和 GB18030 中文文本。段落按空行分隔，长段落自动切分。
Markdown按纯文本参与检索和可选风格画像；保留标题、列表、代码块和链接文字，
不执行代码、不抓取链接、不读取图片或附件，也不承诺完整还原表格与排版。
默认在本机自动生成向量，首次需联网下载公开模型，不需要向量 API Key。
下一次网页交互/刷新会检测资料增删改；模型下载失败时明确提示关键词兜底。
不要直接放 PDF、Word、图片或二进制文件；先导出为 TXT 或 Markdown。

这里的 TXT/Markdown 默认被 Git 忽略，仓库自带的本说明文件除外；不要强制添加个人资料。
本地向量不上传资料；提问时命中的片段会发送给
你配置的模型 API，主动生成可选画像时也会发送有限样本。
请只使用你有权使用且允许发送给该服务的资料。
