# 放入你的 TXT

把一个或多个 `.txt` 文件放在这个目录（支持子目录），再启动或点击网页的
“重新加载资料”。这个 README 不会被作为知识导入。

支持 UTF-8（含 BOM）和 GB18030 中文文本。段落按空行分隔，长段落自动切分。
默认在本机自动生成向量，首次需联网下载公开模型，不需要向量 API Key。
下一次网页交互/刷新会检测 TXT 改动；模型下载失败时明确提示关键词兜底。
不要直接放 PDF、Word、图片或二进制文件；先导出为 TXT。

这里的 TXT 默认不会上传 Git。本地向量不上传资料；提问时命中的片段会发送给
你配置的模型 API，主动生成可选画像时也会发送有限样本。
请只使用你有权使用且允许发送给该服务的资料。
