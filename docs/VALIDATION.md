# 验证范围

这是从维护项目独立整理的新模板，不附带其人物原文、画像、索引或Git历史。

## 上游功能证据（不是本仓库附带的案例资料）

维护项目曾对用户确认属于同一人物的241篇公众号完整原文执行有限真实验收：
197,274字形成622个512维本地片段；1次画像加2次聊天，共3次DeepSeek请求。
其中第一题经Streamlit页面测试，第二题经同一后端带历史对话；验证了历史方法查询及不把历史仓位冒充当前仓位。
画像经代理对照样本修订，不是原作者审核。问答风格仍可能偏报告式，不能据两题保证全面准确或像本人。

B站采样仅得到短片/歌词，真实闭环靠已有同人物公众号原文补齐，不能宣传为单靠该ID自动抓取成功。
本地Whisper引擎还用29秒自有合成语音实测过；真实平台无字幕音轨到人物聊天的整条路径未验收。
这些测试不随新仓库再次付费执行，也不证明任意平台或账号可用。

## 独立模板验证

本仓库测试只使用合成资料和模拟平台/API/向量编码器，默认禁止未模拟的HTTP请求。
覆盖文字和视频采集范围、作者过滤、纯歌词排除、外发同意、画像审核/过期、来源编号、本地索引缓存、
人物切换与刷新、公众号导入、进程超时清理、凭证防护及干净源码发行。

2026-10-15独立验收结果：

- 先用现有依赖验证，119项全部通过；随后在本模板全新`.venv`安装最小依赖和测试依赖，119项再次全部通过（6.96秒）。
- 实际环境为Windows、Python3.8.8，独立安装未继承原项目的site-packages，`pip check`无冲突；
  新环境推荐3.11/3.12，但本轮没有额外声称在这些版本做过全新安装实测。
- 正式安装脚本重复执行会复用环境；没有安装可选ASR依赖、下载语音或向量模型来做本轮验证。
- 使用仅测试进程的假Key，正式启动脚本在8502端口后台启动；首页与健康检查均HTTP200，
  自身停止脚本校验PID后安全停止，8502已释放。原项目8501健康检查前后均HTTP200，没有被停止。
- Streamlit AppTest验证默认人物入口、空TXT提问禁用、模拟采集/画像审核/聊天与刷新等；
  不是人工浏览器操作、实体手机或所有浏览器兼容性验收。
- 独立整理初次验收源码候选81个文件、约278KB；扫描无密钥格式、非空示例凭证、私有原文/模型或损坏的本地文档链接。
  `.env`、`.runtime`和`.venv`均被Git忽略；这是模式审计，不是完整安全证明。
- 新目录初始化全新`main`，没有复制旧Git历史。初次验收时许可证未定，
  `check_release.py --require-license`已验证会拒绝未选许可证的发行准备状态。
- 后续用户明确同意采用MIT并创建独立公开仓库，已添加LICENSE。公开前再次执行带许可证门槛的完整源码审计；
  远程仓库为`https://github.com/wmamba0824/PersonaLens`，原维护仓库保持私有，不改变旧历史或权限。
- 本轮真实聊天API调用0，不使用维护者真实Key；不把上游160项测试或3次真实调用算作本仓库新增成绩。
