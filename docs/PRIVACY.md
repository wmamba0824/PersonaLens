# 隐私、费用与使用范围

## 留在本机的内容

人物原文、运行快照、画像、索引和日志保存于本机。人物页面导入的TXT/Markdown正文保存在对应人物快照，
普通资料问答仍用`knowledge/`。最近10轮人物对话自动存于该人物的`conversation.json`，清空人物对话会清空该文件中的对话。
资料/画像变化后旧版本对话不用于新请求，但磁盘旧文件不会自动清除，下一次保存当前版本时替换。
网页API配置以明文保存在被Git忽略的`.runtime/api-settings.json`，不是加密保险库；已存Key不会发回表单或包含于画像/对话导出。
B站Cookie同样以明文存于`.runtime/bilibili-settings.json`；页面只显示是否填写，输入框不会回填原值。
保存、停用、查看配置都不会请求平台。停用只清空网页配置中的值，不删除旧`.env`或撤销平台会话；用户仍需保护自己的旧配置文件。
不要分享`.runtime`备份；有权读你电脑账户文件的人仍可能读取Key、资料和对话。
默认向量及可选Whisper在本地CPU运行；第一次模型和依赖下载需要网络，但不是上传资料做云端向量或转录。

## 会外发的内容

只有你同意并执行提炼/提问时，才向配置的聊天API发送有限样本，或问题、画像、历史与检索片段，并消耗API额度。
平台采集向平台请求公开内容，部分接口使用本地登录态。媒体请求不带聊天Key，字幕/音轨限制固定平台HTTPS来源。
B站登录配置只添加到固定`api.bilibili.com`的HTTPS请求，禁止跟随重定向；字幕/音轨会话不添加Cookie。
不是完全离线AI，不要导入不允许交给该API处理的私人或保密内容。

## Git 与公开源码

`.env`、`.runtime/`、`.venv/`、TXT/Markdown知识库、模型与索引被忽略（资料目录自带的`README.md`说明除外）。
Markdown只按文本读取，不执行代码或抓取其链接/附件；提问时命中的文本仍可能外发给聊天API。
运行`scripts/check_release.py`复核；强制添加的个人Markdown也会被发布审计拒绝。
忽略规则不会清理已经提交过的内容；如果不慎上传凭证，先在服务商撤销，再处理具体历史，不能只删除当前文件。
本独立仓库不复制维护项目的旧Git历史、原始人物资料或作者画像。

## 可信局域网，而非公共服务

局域网访客登录后可使用此电脑的资料、人物创建功能和API额度，不提供角色隔离。
只有正式本机模式提供API和B站登录配置表单；局域网访客不能通过网页读取或修改Key/Cookie/接口。已获访问权限的访客仍可读取资料、对话并导出，不能视为安全租户。
HTTP不加密，只适合同一可信Wi-Fi；不修改系统防火墙，不要做公网端口转发或分享给陌生人。
这不是多租户产品、公共免费API代理或可直接暴露公网的聊天服务。

## 人物、来源与准确性

系统只做基于资料的AI模拟，不是本人，不证明当前观点、身份或真实私密属性。
只使用你有权处理的内容；同人物关联需人工确认，不代表平台认证或获取版权授权。
人物原文、头像、声音与身份权利不因代码开源而获得许可。
历史仓位、观点等不自动等于今天的事实，不提供实时保证或专业投资建议。
模型推演、字幕错误、多说话人归属和引用语义都需核验；编号正确不保证内容都准确。
